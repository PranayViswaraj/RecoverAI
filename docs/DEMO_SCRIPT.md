# RecoverAI Demo Script

1. Dashboard: point to Revenue at Risk.
2. Click Run Recovery Agent.
3. Explain: Detect → Understand → Predict → Act → Monitor.
4. Select a high-value insufficient-funds payment.
5. Click Why? and explain customer history, probability, expected recovery and ROI.
6. Execute the payment-link action in DEMO_MODE.
7. Select a suspicious transaction and show that it requires human approval.
8. Close with the business outcome: the system prioritizes money recovered, not messages generated.
